## Production SaaS

### [Custimoo](https://custimoo.com) — Product Customization Platform

Multi-tenant SaaS for selling customized apparel and sportswear. Merchants embed a 9-step 2D/3D product builder into Shopify, WooCommerce, or BigCommerce storefronts.

| Layer | Details |
|---|---|
| **Backend** | Laravel 12 · 95+ models · Dual Stripe accounts (DKK + CAD) · Shopify / WooCommerce / BigCommerce cart sync |
| **Admin Panel** | Vue 3 + TypeScript · TanStack Query v5 · Fabric.js + Three.js file generator · 130+ interfaces |
| **Customizer** | Vue 3 Web Component `<v-customizer>` · AI logo generation · 11 languages (Paraglide i18n) · Pantone colors |
